# CLUTCH

Кейсы для компьютерного клуба. Гость открывает страницу и крутит. Сотрудник видит приз и сам зачисляет его в SENET, GameClass, Bada или любой другой программе. На сервер клуба ничего не ставится.

## Запуск

Нужен Node.js 22.

```bash
cd clutch
npm install
npm run dev
```

Сайт: http://127.0.0.1:5174  
API: http://127.0.0.1:8787

Демо-вход на странице «Войти»:

| Кто | Почта | Пароль |
|---|---|---|
| Админ платформы | admin@clutch.local | ClutchAdmin2026 |
| Владелец клуба Nexus | owner@nexus.local | NexusOwner2026 |
| Сотрудник смены | desk@nexus.local | NexusDesk2026 |

Демо-кейс: http://127.0.0.1:5174/c/nexus/smena

Перед настоящим клубом смените эти пароли в кабинете (или удалите файл `data/clutch.db` и поправьте посев в `server/db.js`).

Сборка одного процесса:

```bash
npm run build
npm start
```

Откроется http://127.0.0.1:8787

## Роли

- **Админ** заводит клуб и владельца, может остановить клуб.
- **Владелец клуба** меняет название, цвет, кейсы, шансы, лимиты, подсказки для кассы и людей.
- **Сотрудник смены** видит очередь призов, жмёт «Зачислил» после записи в своей программе и выдаёт коды открытия, если кейс закрыт кодом.

Гостю аккаунт не нужен.

## Как клубу пользоваться

1. Владелец собирает призы. У каждого приза есть текст «что ввести в кассе».
2. Режим «любой по ссылке» или «только с кодом смены».
3. QR или ссылка `/c/адрес-клуба/адрес-кейса` висит на стойке.
4. Гость крутит, на экране остаётся код.
5. Сотрудник находит код в кабинете, зачисляет приз у себя и жмёт «Зачислил».
