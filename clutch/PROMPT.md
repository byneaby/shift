# Промт для ИИ-агента

Собери отдельный веб-сервис CLUTCH. Это не модуль чужой клубной программы и не часть кассы. Клубы ничего не ставят на свой сервер. Гость открывает кейс на нашем сайте без аккаунта. Приз показывается на странице. Сотрудник клуба сам зачисляет его в своей программе учёта (SENET, GameClass, Bada или любой другой) и отмечает это у нас.

Сделай проект готовым к запуску: `npm install`, `npm run dev`, демо-клуб, демо-логины, инструкция на русском.

## Стек

- Node.js 22, ESM.
- Сервер: Express и встроенный `node:sqlite`. Один файл базы `data/clutch.db`, секрет сессии в `data/secret`. Без нативных модулей.
- Клиент: Vite, React, TypeScript, react-router. Свой CSS, без UI-библиотек.
- В разработке Vite проксирует `/api` и `/uploads` на API. В production сервер отдаёт собранный клиент.
- Пароли: scrypt. Сессия: httpOnly cookie, HMAC, 14 дней. Плюс заголовок `Authorization: Bearer` для проверок.

## Роли

1. **Админ платформы.** Видит клубы, создаёт клуб вместе с владельцем, включает и останавливает клуб. Остановленный клуб пропадает с публичной страницы, его люди не входят.
2. **Владелец клуба.** Название, город, фраза, цвет. Кейсы и призы. Сотрудники. Не видит другие клубы.
3. **Сотрудник смены.** Очередь открытий, кнопки «Зачислил» и «Скрыть», выдача одноразовых кодов. Настройки призов ему закрыты.

Гость без роли и без аккаунта.

Демо-пользователи, если база пустая:

- admin@clutch.local / ClutchAdmin2026
- owner@nexus.local / NexusOwner2026 — клуб Nexus Arena, адрес `nexus`
- desk@nexus.local / NexusDesk2026

У демо-клуба кейс `smena` в режиме «любой по ссылке», пауза 15 секунд, шесть призов с картинками, весами и лимитами.

## Данные

Клуб: slug, название, город, фраза, цвет `#RRGGBB`, включён.

Кейс клуба: slug, название, текст для гостя, режим `public` или `ticket`, пауза между открытиями 0–3600 секунд, показывать ли шансы, включён.

Приз: название, текст для гостя, редкость (`common`, `uncommon`, `rare`, `epic`, `legendary`), тип (`bonus`, `time`, `bar`, `custom`), вес от 1, подсказка кассиру, картинка, дневной лимит, общий лимит, участвует или нет.

Открытие: код из 4 символов, снимок приза, статус `open` | `credited` | `void`, хеш IP, время. Повторная отметка уже обработанного открытия не проходит.

Код открытия: 6 символов, один кейс, сгорает на первом успешном спине. Два одновременных запроса с одним кодом проводят только один.

Розыгрыш только на сервере. Клиент получает ленту и индекс победителя и только анимирует. Приз, упёршийся в лимит, из розыгрыша выпадает. День лимита считается по Asia/Almaty. Если призов не осталось, гость видит понятную ошибку, а не пустой приз.

Публичный ответ не содержит подсказку кассиру. Её видит только смена.

## Страницы

Лендинг `/`. Тёмная игровая тема в духе CS2 и Dota 2: чёрный металл, золото, кислотный зелёный, шрифты Unbounded и Manrope. Большие блоки на весь экран, короткие фразы, без канцелярита. Картинки свои, фотореалистичные, без логотипов Valve, без названий чужих брендов и без читаемого текста на изображениях: кейс, ночной зал с компьютерами, администратор, бонус, время, напиток, гарнитура, руна. Блоки: первый экран с кейсом и кнопкой демо, как проходит смена в три шага, зал и фраза что программа учёта клуба не меняется, что видит сотрудник, виды призов, гибкие настройки, две роли, финальный призыв открыть демо.

Страница кейса `/c/:slug` и `/c/:slug/:caseSlug`. Если кейс один, сразу рулетка. Если несколько, сначала выбор. Рулетка на всю ширину, линия по центру, кнопка «Открыть кейс» крупная. В режиме кода поле для кода. После остановки — карточка приза и код, который гость называет администратору. На телефоне всё так же доступно одной рукой. `prefers-reduced-motion` сокращает анимацию.

Вход `/login`. Три демо-кнопки подставляют почту и пароль.

Кабинет админа `/admin`. Форма нового клуба. Список: город, владелец, число открытий, сколько ждут, ссылка на страницу, включить или остановить.

Кабинет клуба `/desk`.

- Смена: ссылка на кейс и копирование, фильтр «ждут / все», живое обновление раз в несколько секунд, карточка с кодом, призом, подсказкой «что ввести в кассе» и кнопками. Для режима кода — выдача нового кода крупно.
- Кейсы, только владелец: режим, пауза, шансы, включение, призы. У приза вес, тип, редкость, лимиты, текст гостю, текст кассиру, картинка из набора или свой файл до 1.5 МБ.
- Клуб, только владелец: название и цвет, люди, отключение сотрудника. Себя отключить нельзя.

Адаптив: лендинг, рулетка и кабинет на ширине 390 и на широком экране. Кнопки не меньше 44px. Ошибки текстом, не кодами.

## Проверка, прежде чем закончить

- Гость без входа открывает `/c/nexus/smena`, видит приз и код.
- Повтор сразу упирается в паузу.
- Сотрудник `desk` видит это открытие и после «Зачислил» оно уходит из очереди «ждут». Вторая отметка того же открытия не проходит.
- Сотрудник не открывает редактор призов.
- Владелец меняет вес и подсказку, гость видит новое название.
- Режим кода: без кода спина нет, использованный код второй раз не проходит.
- Админ создаёт клуб, публичная страница этого клуба открывается, после остановки отдаёт «клуб не найден».
- `npx tsc -p client/tsconfig.json --noEmit` без ошибок.

Не делай интеграций с SENET, GameClass, Bada, LANGAME и SmartShell. Не делай оплату, аккаунты гостей и начисление денег само. Приз в чужую кассу всегда вносит человек.
