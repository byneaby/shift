Важно понять

Мы не заменяем CCBoot

Бездисковая загрузка — ваш фундамент. SHIFT — операционная оболочка клуба поверх неё.

SHIFT это

Оболочка клуба

Касса, сеансы, карта зала, Shell на игровых ПК, бар, брони, клиенты, Telegram, Kaspi, отчёты. Работает по LAN на вашем сервере.

SHIFT это не

Не diskless / не CCBoot

Образы, загрузка ПК по сети, суперклиент — остаются на вашей бездисковой системе. CCBoot (или аналог) покупается и обслуживается отдельно.
