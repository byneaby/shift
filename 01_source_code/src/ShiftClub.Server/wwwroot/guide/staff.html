Сотрудники, отчёты, ПК

Это разделы управления, не ежеминутная касса. Кассиру их обычно не открывают.

Сотрудники

  • Учётка: имя, логин, пароль, роль и набор прав. Список прав.
  • График и отметки смен.
  • Зарплата: начисления по рабочим сменам. Сброс этих цифр есть в опасной зоне и не трогает кассу.
  • Привязка Telegram сотрудника, чтобы ему шли алерты.
  • Режим администратора оболочки: отдельный вход, которым сотрудник открывает служебные действия на ПК, не отдавая гостю стол.
  • Фон экрана входа панели. Это картинка страницы входа, не логотип клуба. Логотип меняется в бренде.

Отчёты

Период: сегодня, вчера, 7 дней, 30 дней, текущий месяц или свои даты.

Кнопка CSV сохраняет текущую вкладку. Файл открывается в Excel. Кодировка UTF-8, чтобы кириллица не разъехалась: если Excel показывает кракозябры, импортируйте файл через «Данные → Из текста», кодировка UTF-8.

Журнал действий сотрудников смотрят отдельным правом аудита. Туда пишется, кто менял цены, баланс и настройки. Это не замена отчёта по деньгам.

Мониторинг

Нагрузка процессора, видеокарты и список процессов по запросу, не постоянный поток. Откройте ПК, запросите снимок. Если машина офлайн, снимка не будет. Это смотр «что запущено», не удалённый рабочий стол.

Новости

Короткие сообщения на оболочку: турнир, акция, «сегодня кухня до 23:00». Старые новости выключайте, иначе лента на ПК превращается в простыню.

Программы

Каталог ярлыков на оболочке: игра или приложение, название, картинка, путь запуска на диске компьютера. Путь должен существовать на игровом ПК. Если игры лежат в бездисковом образе, путь тот же на всех машинах. Каталог не качает игры и не обновляет их файлы.

Обновления клиента

  1. Раздел «Обновления» показывает текущий опубликованный пакет.
  2. Новый пакет публикует тот, кто сопровождает клуб. В панели видна версия.
  3. Оболочки забирают пакет сами. Либо с раздела «Компьютеры» посылают «Обновить клиент» на выбранные ПК.
  4. Не публикуйте пакет в пятницу вечером на полный зал, если некому пройти по ряду и проверить, что оболочка поднялась.
