Панель и права

Панель — это сайт на вашем сервере. Кассир открывает её в браузере на кассе. Отдельной программы на каждый компьютер кассы ставить не нужно.

Вход

Адрес: http://IP-сервера:порт. Порт тот, что указали в мастере, обычно 5080. Логин и пароль владельца задаются при установке. Сменить пароль можно из шапки панели после входа.

На экране входа видно название и логотип клуба. Если лицензия не действует, вместо зала откроется просьба ввести ключ.

Роли

Владелец (owner) видит всё, включая бренд, Kaspi, награды и опасную зону. Кассир — роль смены. Ему включают только нужные права, например просмотр кассы, продажу бара и карточки клиентов. Скрытый раздел в меню не открывается даже по прямой ссылке.

Права, которые можно выдать: бар (смотреть, продавать, заказы, склад), компьютеры (смотреть, управлять, команды), тарифы, зоны, сотрудники, журнал действий, настройки, отчёты, касса, клиенты (смотреть, править, пополнять, корректировать), брони.

Новые людей заводят в «Сотрудниках». Не работайте всей сменой под владельцем: в журнале тогда не видно, кто пробил чек.
