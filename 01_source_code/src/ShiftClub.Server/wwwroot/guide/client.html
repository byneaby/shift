Клиент на компьютеры

На каждый игровой ПК ставится оболочка. Она блокирует стол, пока нет сеанса, и показывает игры, бар и новости. Сервер при этом уже должен отвечать по сети.

Что ввести в установщике клиента

  1. Адрес сервера. Например http://192.168.1.10:5080. Схема http или https, без лишнего слэша в конце. Это адрес панели, который открывается с этого ПК в браузере.
  2. Папка. Установщик предлагает D:\Apps\ShiftClub. На обычном ПК можно оставить. На бездисковой загрузке папка должна лежать на диске, который не стирается при перезагрузке. Системный диск образа часто сбрасывается, и оболочка пропадёт.
  3. Установщик один раз читает название клуба с сервера и подписывает им окно, ярлыки и службу. Если сервер ещё без имени, подпись будет нейтральной, имя подтянется после настройки бренда и обновления.
  4. По желанию оболочка запускается сразу после установки.

Что ставится вместе с оболочкой

  • Сама оболочка и служба, которая следит, чтобы клиент был запущен.
  • Сторож сессии: если оболочку закрыли, она поднимается снова.
  • Обновлятор. Новую версию публикуют в панели, зал подхватывает её сам. Обновления.
  • Ярлыки с именем клуба.

После установки

Компьютер появляется в панели в разделе «Компьютеры». Пока его не подтвердили, сеанс на него не посадишь. Укажите имя, зону, номер на карте и MAC-адрес, если нужно включение по сети. Подробнее в зале.

Один адрес на весь зал Если сервер переехал на другой IP, адрес в клиенте надо обновить, иначе ПК останутся офлайн. На бездисковой системе это правят в образе или на постоянном диске, а не на каждом столе после каждой перезагрузки.
Консоли PlayStation и другие приставки можно поставить на карту зала без оболочки. Сеанс и оплата идут с кассы, экрана блокировки на приставке нет.
