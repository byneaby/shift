Удаление сервера

Удаление снимает автозапуск, правило брандмауэра, запись в приложениях Windows и файлы сервера. База с гостями и кассой по умолчанию остаётся.

Три одинаковых входа

  1. Кнопка в установщике. На первом экране мастера есть «Удалить установленный сервер».
  2. Файл в папке. C:\ShiftClub\Server\Uninstall.exe. Запускайте от имени администратора. Если папку при установке меняли, файл лежит в ней.
  3. Приложения Windows. Параметры → Приложения → установленный сервер клуба → Удалить. Откроется тот же мастер.

Что спросить на экране

Окно показывает название клуба и папку. Галочка «Удалить и базу PostgreSQL этого клуба» стирает гостей, кассу и сеансы. Она видна только если базу ставил сам мастер SHIFT. Чужой PostgreSQL, который уже был на компьютере, эта галочка не сносит.

Без галочки сервер исчезнет, а база останется на компьютере. Так делают перед переустановкой, чтобы не потерять гостей. С галочкой восстановление кассы из программы уже невозможно: нужна отдельная резервная копия, если вы её делали средствами PostgreSQL.

Что именно снимается

  • Задача автозапуска сервера.
  • Процесс сервера, если он был запущен.
  • Правило брандмауэра, которое мастер создал для порта панели.
  • Запись удаления в реестре приложений.
  • Файлы папки сервера. Папка убирается с небольшой задержкой, чтобы окно удаления успело закрыться.
Клиенты на игровых ПК сами не удаляются Оболочка на компьютерах зала — отдельный установщик. После удаления сервера они потеряют связь и останутся на экране входа, пока их не снимут или не укажут новый адрес сервера.
