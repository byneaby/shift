# SHIFT — лист возможностей (feature sheet)

Актуально по продукту (код, сентябрь 2026). Можно копировать блоки на сайт / в КП.

---

## Касса и деньги

- Открытие / закрытие кассовой смены  
- Чеки: игровое время, бар, пополнение, предоплата брони  
- Оплата: наличные, карта, **Kaspi QR (Smart POS)**, перевод, баланс клиента  
- Внесения / изъятия / расходы  
- Возвраты с откатом склада и депозитов  
- Z-отчёт смены  
- В чеках видно **за какой ПК / PS5** оплата  

## Зал и сеансы

- Карта зала: зоны, сетка, редактор layout  
- Статусы: свободен / занят / бронь / офлайн / техработы / пауза  
- Старт сеанса (1 ПК или **пачка**)  
- Продление (1 ПК или **пачка**)  
- Пауза / возобновление / завершение  
- Перенос сеанса на другой ПК (+ WoL, если выключен)  
- **Wake-on-LAN** при старте  
- Банк времени по **зонам** (Standard ≠ VIP)  
- Учёт **PS5 / консолей** на карте (без Shell)  

## Client Shell (на каждом игровом ПК)

- Lock-экран с номером ПК  
- Вход: логин/пароль + **QR Telegram**  
- Активный сеанс, продление, каталог игр  
- Бар с ПК (баланс / в сеанс / у кассы)  
- Новости клуба, вызов администратора  
- Предупреждения до конца сеанса  
- Экстренный оверлей («ВОЕНКОМАТ» и др.)  
- **OTA-обновления** Shell без обхода зала  
- Watchdog (Service + Keeper)  

## Бар и склад

- Категории, товары, фото, остатки  
- POS на кассе  
- Заказы с ПК / из Telegram  
- Доска заказов для выдачи  
- Списания / приходы склада  

## Бронирование

- Свободные ПК по слоту  
- Статусы: ожидание → подтверждена → гость пришёл → активна  
- Предоплата  
- Старт сеанса из брони  
- Soft-hold перед началом  

## Клиенты и лояльность

- Карточка клиента, поиск, блок  
- Баланс + бонусный баланс  
- Уровни лояльности (% на депозит и на время)  
- Стрики визитов → награды  
- Подарок на день рождения  
- SHIFT CASE (кейсы / призы)  
- Comfort-настройки в Shell  

## Telegram

- Mini App для гостя: карта, бар, лояльность, CASE  
- Режим сотрудника: карта, сеансы, бар, смена  
- Вход кассира через TG QR  
- Рассылки (из панели)  

## Публичные экраны клуба

- Сайт клуба (карта, прайс, лояльность)  
- TV-прайс тарифов и бара  
- Promo: Wi‑Fi, Telegram, бонусы, отзывы  

## Администрирование

- Зоны и тарифы (почасовые, пакеты, день/ночь)  
- Сотрудники, роли, права  
- График и payroll  
- Журнал аудита  
- Мониторинг ПК по запросу (CPU/GPU/процессы)  
- Техкоманды: lock, restart, message, update, diagnostics…  
- Отчёты + CSV  

## Технологии (для IT-админа клуба)

- .NET 8 + PostgreSQL + React + WPF Shell  
- **On-prem / LAN-first**, дружит с **CCBoot**  
- SignalR realtime  
- Работа кассы без внешнего интернета  

---

## Чего пока нет (говорить честно)

- Облачный multi-tenant «как SmartShell lk» из коробки  
- Гостевая онлайн-оплата без кассы (remote Kaspi top-up)  
- Полный remote control PS5  
- Managed обновления игр / license pool  
- Встроенная онлайн-касса / ОФД  

Это не слабость на демо — это границы офера. Продавать то, что есть, сильнее конкурентов в LAN + TG + Kaspi.
