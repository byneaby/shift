# Скрипт демо SHIFT (20 минут)

**Цель:** владелец должен сказать «хочу пилот», а не «прикольно, пришлите прайс когда-нибудь».  
**Правило:** не уходить в настройки ролей на 10 минут.

---

## Подготовка (до звонка)
- [ ] Открыта смена на демо-стенде  
- [ ] 2–3 ПК онлайн, 1 офлайн с MAC (WoL)  
- [ ] Тестовый клиент с балансом  
- [ ] Kaspi терминал (если есть) или честно сказать «на стенде имитация / нал»  
- [ ] Telegram Mini App открыт на телефоне  

---

## Минута 0–2 · Крюк
> «Покажу полный круг денег клуба за 20 минут: касса → посадка → Shell → продление → бар → отчёт.  
> Без облака на критичном пути.»

Спросить: сколько ПК, CCBoot?, чем пользуются сейчас.

---

## Сцена 1 · Смена (1 мин)
Открыть `/cash` → показать открытую смену → «без смены продажи не идут».

## Сцена 2 · Клиент (2 мин)
`/customers` → найти / создать → пополнение → уровень лояльности / бонус.

## Сцена 3 · Старт с WoL (3 мин)
`/floor` → выбрать офлайн ПК → Старт → галочка «включить по LAN» → тариф → оплата.  
Показать, что сеанс уже в системе, пока ПК грузится.

## Сцена 4 · Shell (3 мин)
На загруженном ПК: lock → вход (логин или QR TG) → видно время → каталог игр.

## Сцена 5 · Продление пачкой (2 мин)
Ctrl+выбор 2–3 занятых → **Продлить (N)** → сумма × N → оплата.  
«Кассир не кликает по одному».

## Сцена 6 · Бар (2 мин)
Заказ с Shell или быстрый бар с карты → доска заказов → чек.

## Сцена 7 · Telegram (2 мин)
С телефона: карта зала / продление / бар.  
«Гость и старший смены без привязки к стойке».

## Сцена 8 · Финиш смены (2 мин)
Завершить сеанс → lock на ПК → `/cash` чеки (видно ПК) → Z-отчёт / отчёт.

## Закрытие (2–3 мин)
1. Повторить оффер: внедрение + подписка.  
2. Назвать вилку тарифа под их N ПК.  
3. Предложить **пилот 14 дней**.  
4. Договориться о дате.
