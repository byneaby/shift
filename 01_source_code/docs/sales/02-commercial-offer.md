# Коммерческое предложение — SHIFT

**Продукт:** SHIFT — оболочка компьютерного клуба  
**Модель:** разовое внедрение + ежемесячная подписка  
**Валюта:** тенге (KZT)

---

## Что это

SHIFT — **не бездисковая система**.  
Это касса, карта зала, Shell на ПК, бар, брони, клиенты, Telegram и Kaspi  
**поверх уже готового CCBoot / diskless**.

| Слой | Кто |
|------|-----|
| Железо и сеть | Клуб |
| CCBoot / diskless (образы, загрузка) | Клуб · **отдельно от SHIFT** |
| SHIFT (касса, зал, Shell, гости) | Мы |

---

## Цена (одна схема)

| Статья | Сумма |
|--------|-------|
| **Внедрение** | **100 000 ₸** разово |
| **Подписка** | **49 000 ₸ / месяц** |
| **CCBoot** | **не входит** — покупаете / платите отдельно |

Других тарифов внедрения (Express / Standard / Arena) **нет**.

### Что входит во внедрение 100 000 ₸
- установка панели и API на сервер клуба  
- Shell в контур клуба (поверх вашего образа)  
- зоны, тарифы, касса, базовое обучение  

### Что входит в 49 000 ₸/мес
- право использовать актуальную версию  
- обновления панели и Shell (OTA)  
- поддержка в рабочие часы  

### Что не входит
- CCBoot и любая diskless-лицензия  
- образы Windows / игры  
- железо, интернет  
- кастом (бот, дизайн) — отдельно
