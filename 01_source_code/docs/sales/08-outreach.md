# Холодные сообщения

## 1. Первый контакт

Привет{, имя}! Пишу владельцам клубов на CCBoot.

Делаем **SHIFT** — оболочку клуба поверх вашей бездисковой системы  
(касса, карта зала, Shell, бар, брони, Telegram, Kaspi).  
Это **не** замена CCBoot — diskless остаётся вашим.

Цена: внедрение **100 000 ₸**, дальше **49 000 ₸/мес**. CCBoot — отдельно.

Могу показать живое демо 20 минут. Если интересно — «демо» и сколько ПК.

---

## 2. Сколько стоит?

Только так:
• внедрение — 100 000 ₸ разово  
• подписка — 49 000 ₸/мес  
• CCBoot / образы / железо — не входят  

Удобно созвониться {день}?

## 3. Уже есть SmartShell

Понял. Имеет смысл, если хотите LAN-first и фиксированную подписку без «× ПК».
