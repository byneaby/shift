# Как бы я строил SHIFT, чтобы конкурировать

Личное продуктовое мнение на базе текущего кода и рынка (Senet, SmartShell и др.).  
Не бэклог спринта — **стратегия на 18 месяцев**.

## 1. Честная стартовая позиция

У вас уже есть то, на чём спотыкаются самописные клубы:

- нормальный домен (сессии, ledger, касса, бар, роли);
- Shell + Service + Keeper + OTA;
- Web-панель операционки;
- Telegram как канал гостя/стаффа;
- понимание CCBoot (исходники на C:, publish на D:).

Этого **достаточно**, чтобы продавать **первым 5–20 клубам как Local**.  
Этого **недостаточно**, чтобы отнять долю у SmartShell/Senet на их поле (облако, платежи, консоли, бренд).

Стратегия: **не догонять всё сразу**, а стать №1 в узкой категории, потом расширять.

## 2. Категория, в которой можно победить

**«Лучшая LAN/on-prem club OS для diskless-клубов в KZ/СНГ».**

Почему эта категория свободна:

- облачные лидеры оптимизированы под подписку и удалёнку;
- админы CCBoot ненавидят «ещё один облачный агент, который отваливается»;
- вам не нужно 1700 клубов, чтобы быть прибыльными — нужны 30–50 платящих с Care.

Позже (год 2): гибрид «локальный биллинг + cloud owner app» — уже с репутацией стабильности.

## 3. Принципы продукта (как бы правил)

1. **Кассир за 3 клика** важнее красивого дашборда владельца.  
2. **Деньги и время — священны**: идемпотентность, аудит, нельзя «поправить втихую» без права.  
3. **Образ CCBoot священен**: никогда не класть исходники/секреты на Games D:.  
4. **Один счастливый референс-клуб** > десять недоделанных модулей.  
5. **Продаём исход**, не модуль: «смена закрылась без сюрпризов», «гость сел сам через TG».  
6. Не строить game-update платформу, пока не зарабатываете на биллинге.

## 4. Дорожная карта (приоритеты)

### Фаза A — «Можно продавать Local» (0–3 мес)

Цель: любой новый клуб поднимается по runbook за 1–2 дня.

| Работа | Зачем |
|--------|-------|
| Мастер первого запуска (branch, зоны, тарифы, владелец, первый ПК) | Сейчас знание в голове — должно быть в UI/скрипте |
| Лицензия: лимит ПК + срок (файл или простой activation) | Иначе нельзя масштабировать продажи |
| Импорт клиентов CSV + экспорт отчётов | Миграции и доверие бухгалтерии |
| Жёсткий чек-лист приёмки + демо-видео | Продажи |
| Вычистить путь/доки под бренд `C:\ShiftClub\Project` | Онбординг партнёров |
| Стабильность shell: lock, update, keeper — zero drama | Репутация |

**Не делать в фазе A:** консоли, облачный multi-tenant, магазин игр Senet-уровня.

### Фаза B — «Гость платит сам» (3–8 мес)

Цель: кассир не нужен для пополнения/брони у части гостей.

| Работа | Зачем |
|--------|-------|
| Платёжный адаптер под KZ (Kaspi и/или локальный эквайринг) | Senet продаёт этим |
| Self top-up в TG Mini App + статус оплаты | Снижает очередь |
| Бронь end-to-end: гость → предоплата → посадка | Деньги |
| Промокоды / подарочные сертификаты | Маркетинг клуба |
| Уведомления: конец сеанса, бронь через час | Retention |

### Фаза C — «Владелец не в зале» (6–12 мес)

| Работа | Зачем |
|--------|-------|
| Secure remote panel (VPN-пакет или cloud proxy с 2FA) | Ответ на Senet remote |
| Дашборд владельца: выручка дня, загрузка, алерты | Покупка Care |
| Multi-branch в одной панели | Сети |
| Push/Telegram алерты: касса не открыта, ПК офлайн пачкой | Ops |

### Фаза D — «Паритет с лидерами выборочно» (12–18 мес)

Только если фазы A–C кормят кассу:

- консоли как устройства с отдельным тарифом;
- shop в shell (комбо);
- возрастной/зонный контент-контроль;
- опциональный hosted SHIFT Cloud;
- партнёрский канал (white-label для сборщиков клубов).

## 5. Чего я бы сознательно не копировал

| Фича конкурентов | Почему не сейчас |
|------------------|------------------|
| Собственная библиотека игр / автообновление игр | Это другой бизнес (хранение, CDN, поддержка) |
| «72 часа под ключ» как у Senet без команды полевых инженеров | Сожжёт маржу |
| 3 тарифа × 10 device tiers в публичном прайсе | Путает, пока нет объёма |
| Мобильное store-приложение | TG Mini App закрывает 80% в СНГ дешевле |
| Universal payment (Stripe+Mercado+…) | Сначала 1–2 локальных метода идеально |

## 6. Архитектурные ставки под продукт

Уже хорошие:

- .NET 8 + PostgreSQL + React + WPF — нормальный «серьёзный» стек.
- Permission-based roles.
- OTA клиента.
- Отделение Domain/Application.

Что добавить под продажи:

1. **`License` / `Tenant`** в домене (даже для одного клуба) — лимит ПК, expiresAt, features flags.  
2. **Feature flags** (`Payments.Kaspi`, `Consoles`, `MultiBranch`) — одна сборка, разные SKU.  
3. **Provisioning script** `New-ShiftClub.ps1` — поднять Server+DB+первый owner.  
4. **Telemetry opt-in** (версия, число ПК, ошибки shell) — иначе поддержка слепая.  
5. **Backup/restore wizard** — продаёт спокойствие владельцу.

Чего избегать:

- Переписывать Shell на другой UI-стек «потому что Senet красивый» — сначала деньги.
- Тащить исходники в облако клиентов «для удобства».
- Смешивать runtime `C:\ShiftClub\Server\data` обратно в git-дерево.

## 7. Команда и экономика (грубо)

Минимально жизнеспособная продуктовая машина:

- 1 product/owner (вы)  
- 1–2 разработки (backend+client уже в одном контуре)  
- 1 человек внедрения/поддержки (можно партнёр)

Unit-экономика, к которой стремиться:

- внедрение окупает 1–2 месяца работы;
- Care даёт предсказуемый MRR;
- кастом (TG/интеграции) — высокая маржа;
- не чинить бесплатно вечно «потому что свой клуб».

## 8. Северная звезда (метрика продукта)

Не «число фич», а:

> **Минуты от «гость у двери» до «игра запущенa и деньги учтены»**  
> и  
> **% смен, закрытых без ручной правки баланса.**

Если эти две цифры лучше, чем у конкурента на одинаковом клубе — вы побеждаете даже с более бедным прайсом фич.

## 9. Рекомендуемый порядок решений «прямо сейчас»

1. Зафиксировать позиционирование Local (этот пакет docs).  
2. Сделать публичный one-pager + прайс-черновик.  
3. Прогнать демо-скрипт на своём клубе, записать 5 минут.  
4. Добавить лицензионный лимит ПК (даже простой).  
5. Найти 1 партнёра-сборщика клубов.  
6. Только потом — Kaspi/self-pay.

## 10. Резюме одной фразой

**Стать «SmartShell для тех, кто хочет свой сервер и CCBoot» — быстрее и честнее, чем стать вторым Senet.**
