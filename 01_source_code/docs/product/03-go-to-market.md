# Как продавать SHIFT

## 1. Что продаём на словах (позиционирование)

Не: «ещё одна программа для клуба как SmartShell».

Да (на ближайшие 12–18 мес):

> **SHIFT — локальная система управления компьютерным клубом под diskless (CCBoot): касса, зал, shell, Telegram. Работает у вас на сервере, без обязательной облачной подписки за каждое кресло.**

Вторичные формулировки под сегмент:

- Владельцу: «контроль кассы и сотрудников, меньше сливов, карта зала, отчёты».
- Админу: «shell + OTA + WoL, без ручного обхода 40 ПК».
- Кассиру: «посадка за 10 секунд, бар, бронь».
- Гостю: «Telegram / QR, баланс и время по зонам».

## 2. Упаковка продукта (SKU)

Предлагаемая линейка (простая, как у рынка):

| SKU | Что входит | Для кого |
|-----|------------|----------|
| **SHIFT Local** | On-prem API + Web + Shell + OTA, 1 филиал | Клубы, которым важен LAN |
| **SHIFT Local + Care** | Local + удалёнка/выезд + обновления N мес | Кто боится «остаться без поддержки» |
| **SHIFT Network** (позже) | Несколько Branch + owner portal | Сети 2+ клуба |
| **SHIFT Cloud** (ещё позже) | Hosted панель + лицензия устройств | Кто хочет «как SmartShell» |

Не плодить 7 тарифов как Senet на старте. Три слова: **Local / Care / Network**.

## 3. Ценообразование (черновик логики)

Рынок ориентир (публичные сравнения, не прайс SHIFT):

- iCafeCloud ~60 ₽/ПК/мес  
- SmartShell от ~280 ₽/ПК/мес  
- Club Keeper ~300 ₽/ПК/мес  
- LANGAME часто выше  

**Как бы я ставил SHIFT Local в KZ/СНГ:**

| Компонент | Идея |
|-----------|------|
| Внедрение | Разово: N × (настройка сервера + образ + 1 день обучения). Это основной кэш на старте. |
| Лицензия | Либо **год вперёд** (проще кассе клуба), либо **мес × ПК**, но дешевле облачных на 20–40%. |
| Care | Фикс/мес за поддержку + SLA «вечер пятницы». |
| Кастом | Telegram-бот клуба, карта, интеграции — отдельно, маржа высокая. |

Пример вилки для клуба **40 ПК** (иллюстрация, не оферта):

- Внедрение: эквивалент 150–400 тыс. ₽ / 800k–2M KZT (зависит от выезда и готовности образа).  
- Год Local: заметно ниже, чем 40 × 280 ₽ × 12 у облака — **это ваш главный слайд TCO**.

Важно: пока нет лицензионного сервера в коде — продажа идёт как **внедрение + договор + ключ/контракт вручную**. Это нормально для первых 5–15 клубов.

## 4. Воронка продаж

```text
Лид (Telegram / сарафан / визит в клуб)
  → 20-мин демо на вашем стенде или TeamViewer на их зале
  → Пилот 14 дней на 5–10 ПК (или теневой зал)
  → Счёт на внедрение
  → День 0–1: сервер C:, PostgreSQL, API, панель
  → День 1–2: shell в образ, регистрация ПК, тарифы/зоны
  → День 3: обучение кассиров + чек-лист приёмки
  → Care-подписка
```

**Демо-скрипт (обязательные 8 сцен):**

1. Открыть смену.  
2. Создать/найти гостя, пополнить.  
3. Старт сеанса на офлайн-ПК с галочкой WoL.  
4. Shell: вход, видно время.  
5. Продление с панели и из TG.  
6. Бар + чек.  
7. Конец сеанса → lock.  
8. Отчёт за смену.

Если демо > 25 минут без этих сцен — продукт «не продаётся», это UX-баг.

## 5. Каналы

| Канал | Приоритет | Зачем |
|-------|-----------|-------|
| Сарафан владельцев клубов | **P0** | В нише решает доверие |
| Telegram-чаты админов CCBoot / клубов | **P0** | Там живут ЛПР по IT |
| Партнёрство с установщиками CCBoot / «компьютерных клубов под ключ» | **P0** | Они уже продают железо |
| Контент: «миграция со SmartShell», «LAN без облака» | **P1** | SEO/доверие |
| Холодные визиты по городу | **P1** | Пока мало бренда |
| Marketplace / каталоги (a2is и т.п.) | **P2** | Позже, когда есть сайт и прайс |

## 6. Что должно быть «продаваемым артефактом» (не код)

До массовых продаж завести:

1. **Одностраничный сайт** (не внутренний `site/` клуба) — продукт SHIFT.  
2. **Договор-оферта + акт внедрения + NDA** (шаблоны).  
3. **Чек-лист приёмки** на 1 страницу.  
4. **Прайс** в PDF (Local / Care).  
5. **Запись демо 5 минут**.  
6. **Runbook установки** нового клуба (у вас уже зачатки в `docs/SHELL-SYSTEM.md` — вычистить под бренд Product).  
7. **Лицензионный ключ или online activation** (минимум: файл лицензии с лимитом ПК и датой).

Без п.1–4 вы продаёте «услугу знакомым», не продукт.

## 7. Миграция с конкурентов

Обещать миграцию выборочно:

| Откуда | Реалистично |
|--------|-------------|
| Excel / тетрадка | Да, быстро |
| iCafe / старый локальный софт | Да, ПК+тарифы руками + импорт клиентов CSV |
| SmartShell / Senet | Осторожно: клиенты/балансы CSV, сессии не тащить; продавать «чистый старт сезона» |

Не обещать «перенесём всё за ночь» — конкуренты этим убивают доверие.

## 8. Риски продаж

- Поддержка 24/7 ожидают как у SmartShell — закладывайте Care или честно говорите «рабочие часы + аварийный чат».  
- Фискализация/налоги — юридический блокер, не фича UI.  
- Один сильный клуб-референс (ваш SHIFT) важнее десяти фич на слайде.  
- Пиратство on-prem: лицензия + периодический phone-home опционально + договор.

## 9. Метрики, за которыми смотреть

- Время от лида до пилота.  
- Время внедрения «голый сервер → первая оплаченная смена».  
- Retention Care на 3/6/12 мес.  
- NPS кассира (отдельно от владельца!).  
- Доля смен без ручных правок баланса (качество процесса).
