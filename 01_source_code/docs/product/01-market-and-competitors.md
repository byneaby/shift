# Рынок и конкуренты

## 1. Что покупает владелец клуба

Владелец платит не за «красивую карту зала», а за три исхода:

1. **Меньше воровства и ошибок кассы** — сеансы, баланс, бар, смены, права сотрудников.
2. **Больше загрузки** — брони, лояльность, удобный вход гостя, продление без очереди к кассе.
3. **Меньше гемора админа** — shell на ПК, удалённые команды, обновления клиента, мониторинг, стабильность с diskless (CCBoot / аналог).

Вторично: отчёты для себя/инвестора, брендинг shell, интеграции с Kaspi/онлайн-кассой, сеть филиалов.

## 2. Как устроен рынок ПО для комклубов

| Модель | Как берут деньги | Кто так живёт |
|--------|------------------|---------------|
| **SaaS за устройство / мес** | 60–800+ ₽/ПК/мес (или эквивалент в KZT), иногда tier по числу ПК | SmartShell, Senet, Gizmo, iCafeCloud, Club Keeper, LANGAME |
| **Разовое внедрение + подписка** | Setup fee + monthly | Senet (базовая интеграция обязательна), крупные внедрения |
| **On-prem / лицензия** | Разово или год | Старые системы, часть локальных разработок |
| **Бесплатно / freemium** | Лид → апгрейд | Пробные периоды 14–30 дней, «бесплатно 3 мес» |

Типичный клуб 30–60 ПК платит конкурентам порядка **десятков–сотен тысяч ₽/год** только за софт, плюс время на внедрение.

Рынок СНГ/KZ: SmartShell заявляет **1700+ клубов / 22 страны** — это уже зрелый продукт с сильным брендом. Senet давит на cloud + платежи + консоли + game updates. Локальные аналоги конкурируют ценой и «мы рядом / на русском / на KZT».

## 3. Главные конкуренты (срез)

### SmartShell (smartshell.gg)
- **Сила:** зрелый product-market fit в RU/KZ, узнаваемость, shell+admin+бронь+отчёты+магазин, SaaS кабинет `lk` / `admin`, масштаб.
- **Модель:** подписка (часто от ~280 ₽/ПК/мес в публичных сравнениях; точная цена в ЛК).
- **Слабость для части клубов:** зависимость от облака/интернета, «все как у всех», ограничение кастома, ощущение «мы платим вечно».

### SENET (senet.cloud)
- **Сила:** позиционирование как платформа venue management: ПК+консоли, тарифы/абонементы, лояльность, shop в shell, booking, payment gateways (Stripe/Kaspi/LiqPay…), remote, game updates, mobile app — в тарифах Basic/Business/Premium.
- **Модель:** device-based tiers + обязательная базовая интеграция + опциональный managed service.
- **Слабость:** цена/пакетность; «enterprise cloud» может быть избыточен маленькому клубу; внедрение продаётся как сервис.

### Gizmo / LANGAME / GeexClub / Club Keeper / iCafeCloud / CYBERSOFT
- Разный возраст и UX, но набор почти один: биллинг, shell, мониторинг, бар/склад, отчёты.
- **iCafeCloud** — дёшево (от ~60 ₽/ПК), часто в связке с CCBootCloud.
- **Club Keeper** — ~300 ₽/ПК, акцент на простоту.
- **LANGAME** — сильнее в кибераренах/франшизах, обычно дороже.

### CCBoot / diskless-экосистема
Не прямой конкурент по биллингу, но **обязательный контекст**: большинство клубов живут на образах. Продукт, который плохо дружит с diskless, проигрывает на внедрении, даже если UI красивый.

## 4. Что клиенты реально сравнивают на демо

Чек-лист владельца за 30 минут:

1. Посадить гостя / списать время / продлить / завершить.
2. Карта зала: занято / свободно / офлайн.
3. Касса: смена, нал/безнал, бар.
4. Shell: вход, баланс, каталог игр, lock после конца.
5. Бронь: сайт / TG / админка.
6. Права кассира vs владельца, нельзя ли «накрутить».
7. Обновление клиента без ручного обхода ПК.
8. Работает ли при падении интернета / только LAN.
9. Сколько стоит на мои N ПК через год.
10. Кто приедет / ответит, если «всё упало в пятницу вечером».

## 5. Сегменты покупателей

| Сегмент | Размер | Что хочет | Чем взять |
|---------|--------|-----------|-----------|
| Малый клуб 10–25 ПК | много | дёшево, просто, быстро | цена + 1-день setup |
| Средний 30–80 ПК | основной | стабильность, касса/бар, shell | полный контур + поддержка |
| Киберарена / сеть | мало, жирные | филиалы, бренд, аналитика, консоли | multi-branch + remote owner |
| «Уже на SmartShell/Senet» | миграции | дешевле / on-prem / меньше зависимости | TCO + миграция данных + LAN-first |

## 6. Вывод для SHIFT

Конкурировать «фича в фичу» с Senet/SmartShell в лоб — дорого и долго. Реалистичные углы атаки:

1. **LAN-first / on-prem** для клубов на CCBoot (как уже устроен ваш клуб).
2. **Честная цена** и прозрачный TCO без обязательного «облачного налога».
3. **Глубокая кастомизация под клуб** (Telegram, зоны, time banks, WoL) быстрее, чем у массового SaaS.
4. Позже — **гибрид**: локальный биллинг + опциональный cloud для владельца с телефона.
