# Матрица возможностей SHIFT

Оценка по состоянию кода/панели в `C:\ShiftClub\Project` (июль 2026).  
Легенда: **Есть** / **Частично** / **Нет** / **Сильно** (лучше типичного MVP).

## 1. Поверхности продукта

| Поверхность | Статус | Комментарий |
|-------------|--------|-------------|
| Staff Web-панель | **Есть** | Зал, касса, бар, клиенты, тарифы, зоны, сотрудники, отчёты, новости, софт, обновления, TG-настройки |
| Client Shell (WPF) | **Есть** | Lock, сеансы, каталог, новости/бар, heartbeat, OTA |
| Client Service / Keeper / Updater | **Есть** | Watchdog + ACL + обновления — редкий для самописных зрелый контур |
| Telegram Mini App | **Есть** | Профиль, время по зонам, карта/стафф-действия |
| Публичный лендинг / сайт | **Частично** | Есть `wwwroot/site`, не полноценный self-service портал сети |
| Мобильное приложение гостя (store) | **Нет** | У Senet — отдельный selling point; у вас TG закрывает часть |
| Owner cloud «из дома без VPN» | **Нет / Частично** | Сейчас клубный LAN API; remote = туннель/VPN вручную |
| Multi-tenant SaaS (много клубов на одном облаке) | **Нет** | Есть `Branch`, но продукт заточен под один клуб/сервер |

| Бронирование | **Есть** | Есть |

| Комбо / пакеты «ПК+бар» | **Частично** | Senet Business+ |
