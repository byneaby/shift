SHIFT Club — идеи и варианты маркетинга
Дата: 15.09.2026
Акция сейчас: «−30% пока обновляем» (только пакеты 2+1 / 3+2 / день / ночь) до 30.09.2026 + кейс за создание аккаунта.

================================================================================
1. ЧТО УЖЕ КРУТИМ (коротко для команды)
================================================================================
• Скидка −30% на пакеты, не на почасовку — честно говорим гостю: «выгоднее брать пакет».
• Название акции = оффер + повод: «пока обновляем» (ремонт/апгрейд/новый сезон — подставить факт).
• Регистрация → ключ → SHIFT CASE на той же странице /promo/upgrade (или у кассы, если аккаунт с ПК).
• Цель воронки: новый аккаунт + первая платёжка пакетом + повод вернуться за призом/балансом.

================================================================================
2. СООБЩЕНИЯ (готовые формулировки)
================================================================================
A. Коротко (Stories / экран / стикер):
   «−30% на пакеты пока обновляем. До 30.09. Создай аккаунт — крутим кейс.»

B. Честно и спокойно (пост):
   «Пока клуб обновляется — пакеты 2+1, 3+2, день и ночь со скидкой 30%.
    Почасовой тариф без скидки. За новый аккаунт открываем SHIFT CASE.»

C. Для кассы (скрипт 10 сек):
   «Есть аккаунт? Нет — создадим за минуту и сразу кейс. Пакеты сейчас −30% до конца месяца.»

D. Для ПК (если гость зарегистрировался на Shell):
   «Ключ уже на аккаунте — подойди к кассе, покрутим кейс и выдадим приз.»

E. Telegram CTA:
   startapp=upgrade → регистрация / кейс в Mini App.

================================================================================
3. КАНАЛЫ И ФОРМАТЫ
================================================================================
• TV /promo/upgrade?tv=1 — прайс со скидкой + QR в бота.
• Телефон / планшет у входа — форма «создать и крутить кейс».
• 2ГИС / Instagram / TikTok — один визуал: зачёркнутая цена пакета + «−30%» + срок.
• WhatsApp / рассылка по базе (если есть согласия) — только тем, кто не был 14+ дней.
• Стикер на кассе + карточка «ПК → касса → кейс».

================================================================================
4. ВАРИАНТЫ ОФФЕРОВ (после 30.09 или параллельно)
================================================================================
1) «Пакет + друг»: купи 3+2 — второй гость час по фикс-цене (не −30%, чтобы не каннибализировать).
2) «Ночной вторник»: ночной пакет −20% только в будни 00–08 (если загрузка слабая).
3) «Первый депозит»: бонус за пополнение уже есть — упаковать как «залей 5000 → +бонус + ключ кейса».
4) «Вернись за 7 дней»: второй визит в неделю — +30 мин в банк (не скидка на чек).
5) «Студенческий час» 14–17 будни: только VIP/Standard почасовка −15% (если нужно заполнить день).
6) Турнир / LAN-вечер: билет = пакет дня, без отдельной скидки — контент вместо дисконта.
7) Бар-бандл: пакет + напиток фиксированным комбо (маржа бара).
8) «Кейс за отзыв 2ГИС» — 1 ключ после модерации отзыва (редко, антифрод на кассе).

================================================================================
5. ИДЕИ КОНТЕНТА (без бюджета на продакшн)
================================================================================
• До/после зоны (фото обновления) + ценник пакета.
• 15-сек Reels: рулетка кейса + реакция гостя (с согласием).
• «Сколько часов в 3+2» — калькулятор в сторис (свайп-вверх на /promo/upgrade).
• UGC: «покажи чек пакета со скидкой — репост в сторис клуба».
• Карта зала + «свободные ПК сейчас» (уже есть /display) в сторис вечером.

================================================================================
6. МЕТРИКИ НА 2 НЕДЕЛИ АКЦИИ
================================================================================
Смотреть каждый день:
• Новые аккаунты (касса / Telegram / campaign page).
• Открытия кейса (registration keys).
• Доля чеков с пакетами 2+1 / 3+2 / день / ночь vs почасовка.
• Выручка и средний чек vs те же дни прошлой недели.
• Повторный визит в течение 7 дней у новых аккаунтов.

Стоп-сигналы:
• Растёт только почасовка / падает средний чек → акцент в скрипте на пакеты.
• Много регистраций, мало депозитов → касса предлагает «пополни и забери приз».
• Очередь на кейс у кассы → TV-демо кейса + выдача призов пачкой раз в час.

================================================================================
7. МИНИ-ПЛАН НА НЕДЕЛЮ
================================================================================
Пн: обновить экраны (/promo/upgrade, /display), брифинг кассы.
Вт: пост + Stories, стикер на вход.
Ср: прогрев «осталось N дней», UGC-репост.
Чт: акцент на ночной пакет / будни.
Пт–Сб: пик трафика — только скрипт кассы + кейс, без новых офферов.
Вс: разбор метрик, решение продлевать / менять % / закрывать.

================================================================================
8. ЧЕСТНЫЕ ОГРАНИЧЕНИЯ (чтобы не подставлять клуб)
================================================================================
• Не обещать −30% «на всё» — только пакеты.
• Приз кейса с claim — только через кассу, не «сам себе».
• Срок акции на всех носителях одинаковый (до 30.09).
• Не смешивать с другими % на те же пакеты без пересчёта маржи.
