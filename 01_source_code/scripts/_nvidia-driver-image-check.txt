5) SuperClient save failed / writeback wiping driver installs?
--------------------------------------------------------------------------------
Evidence:
  A) Auto PnP is intentionally refused in Super mode (hard fail message).
     Expectation that "enable SuperClient then let CCBoot inject NVIDIA" will
     FAIL every time by design.

  B) Manual installer during SuperClient would land on *.Super.vhd writeback.
     On disable_super_client, parent is opened write-mode (implies merge attempt).
     No explicit "save failed" in Jul 17–19 logs.
     No *.Super.vhd left on E:\ now (cleanup after disable).

  C) Normal diskless writeback (G:\PC##-E....vhd / I:\PC##-E....vhd) is discarded
     on reboot — that ALWAYS wipes unsaved driver installs. Only InfGPU auto PnP
     into the shared image (or a successful SuperClient save into parent) persists.

  D) Therefore: most likely user failure mode =
       SuperClient enabled -> auto PnP fails -> user installs NVIDIA manually OR
       expects PnP -> disable Super without verifying Device Manager / nvidia-smi
       on a FRESH normal boot from parent image.
