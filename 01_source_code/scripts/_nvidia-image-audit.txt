5) LIKELY ROOT CAUSES — "NVIDIA apps broken on ALL diskless clients"
================================================================================
ROOT-CAUSE HYPOTHESIS (primary):

  Clients get a DCH NVIDIA display driver via CCBoot GPU PnP / InfGPU, so the
  GPU itself can work for games, but NVIDIA Control Panel is ONLY shipped as a
  Windows Store AppX (NVIDIACorp.NVIDIAControlPanel). CCBoot GPU PnP logs show
  driver staging (DISM DriverStore + registry) and never mention AppX provisioning
  (/Add-ProvisionedAppxPackage) or successful NVCPL registration.

  On diskless boots with ~0.2 MB system writebacks, a Store/AppX Control Panel
  that is not correctly provisioned into the base VHD will fail for every client
  the same way: missing/broken Start menu tile, nvcplui.exe fails, or CPL cannot
  talk to NVDisplay.Container / driver store.

  Official DisplayDriver.nvi itself installs CPL via DISM AppX provision AND
  expects Program Files\NVIDIA-style container layout; InfGPU’s Panel overlay
  copies WindowsApps + panel.reg but CCBoot’s automated GPU PnP path appears
  driver-centric ("already staged / skip DISM") — insufficient for AppX CPL.

SECONDARY / CONTRIBUTING:

  A) "NVIDIA App" / GeForce Experience are NOT present in InfGPU at all — if
     staff mean those products, they were never part of the club image pipeline.
  B) No classic Win32 Control Panel under Program Files\NVIDIA Corporation in
     the InfGPU Panel overlay — modern DCH stack requires the Store CPL.
  C) Affects ALL clients because all share the same base VHDs + same InfGPU
     package (VEN_10DE RTX 30xx-class DEV_2504/2507 seen in logs).
  D) Server has no NVIDIA stack (cannot validate CPL locally on 192.168.1.250).

WHAT THIS IS PROBABLY NOT:
  - Not a ShiftClub Shell bug (no NVIDIA code there).
  - Not missing InfGPU entirely (package exists; GPU PnP reports success).
  - Not per-PC hardware uniqueness (club-wide identical failure pattern fits
    shared image + AppX/CPL gap).

RECOMMENDED FIX DIRECTION (not performed — audit only):
  1. SuperClient on one PC: full NVIDIA installer (driver + Control Panel),
     verify nvcplui / AppX provisioned for all users, save image to both active
     VHDs (24.02.2026 and STANDART).
  2. Or offline: DISM /Add-ProvisionedAppxPackage of NVCPL appx into mounted
     VHDs + ensure NVDisplay.ContainerLocalSystem + panel.reg + DriverStore
     hash folder match; keep writeback disabled until validated.
  3. Or switch to a "Standard" (non-DCH) driver package with classic CPL if
     still available for these GPUs (often preferred in cafés/diskless).
  4. Do NOT expect GeForce Experience / NVIDIA App unless separately installed
     into the image (and they are writeback-hostile).
